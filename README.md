# Explorando Tags Básicas do HTML

Um projeto desenvolvido para apresentar, explicar e exemplificar o uso de **10 tags fundamentais do HTML5**.

## Tags HTML Abordadas

Abaixo estão as 10 tags explicadas e exemplificadas no projeto:

1. **`<h1>` a `<h6>`** — Define títulos e a hierarquia de cabeçalhos na página.
2. **`<p>`** — Cria parágrafos de texto.
3. **`<hr>`** — Insere uma linha horizontal para divisão de seções.
4. **`<img>`** — Adiciona imagens à página.
5. **`<b>`** — Aplica formatação de texto em negrito.
6. **`<br>`** — Insere uma quebra de linha no texto.
7. **`<li>`** — Define itens dentro de listas ordenadas (`<ol>`) ou não ordenadas (`<ul>`).
8. **`<title>`** — Define o título da página exibido na aba do navegador.
9. **`<a>`** — Cria links/hiperlinks de navegação.
10. **`<head>`** — Elemento que contém os metadados e configurações da página.
